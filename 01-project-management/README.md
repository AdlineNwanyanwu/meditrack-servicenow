
# MediTrack — Project Management

## Overview

This folder documents the project management activities, planning decisions, and coordination processes for MediTrack, a ServiceNow medical equipment management application developed as part of the ServiceNow RiseUp capstone project.

## Project Information

- **Project:** MediTrack — Medical Equipment Management
- **Team:** Langston Team (Group 2)
- **Team Size:** 5 Members
- **Project Manager:** Adline Nwanyanwu
- **Platform:** ServiceNow
- **Status:** In Development

## Project Management Responsibilities

My responsibilities as Project Manager include:

- Defining and maintaining project scope
- Coordinating a five-member development team
- Organizing team responsibilities and deliverables
- Monitoring project progress
- Facilitating team communication
- Identifying and addressing project risks
- Coordinating testing and final presentation activities

## Project Management Deliverables

This folder will contain:

1. Project Charter
2. Project Scope and Requirements
3. Team Roles and Responsibilities
4. Project Milestones and Timeline
5. Risk and Issue Tracking
6. Testing and Delivery Coordination
7. Project Retrospective

## Project Management Approach

MediTrack uses a collaborative, milestone-based approach to application development.

The project involves defining requirements, dividing technical responsibilities, configuring the ServiceNow application, integrating components, testing functionality, and preparing a final demonstration.

## Current Status

Project management documentation is being organized and will be updated as the project progresses.
